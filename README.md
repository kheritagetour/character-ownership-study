## 1. 실험 설계 요약

| 항목 | 내용 |
|---|---|
| 설계 | 참가자 간 설계(between-subjects), 2조건 |
| IV | AI 이미지 생성에서의 사용자 관여 형태 — **A** 단일 프롬프트 / **B** 반복 프롬프트 |
| 유일한 차이 | AI 결과를 본 뒤 **수정할 수 있는지** 여부 |
| N | 12명 (조건당 6명), 4명 단위 블록 무선배정 |
| 1차 DV | 심리적 소유감 PO (Chung et al., 2024 · 5문항 · 7점) |
| 탐색 | 의도 일치도 IA (자체 개발 · 3문항 · 컨셉 시트/스케치 옆에서 평정) |
| 2차 DV | 지각된 저자성 AU (2문항) + 공개 시 저자 표기 (Draxler et al., 2024) |
| 조작 점검 | 지각된 창작 통제감 CC (Gong & Chen, 2026 · 3문항) |
| 공변량 | 지각된 품질, 지각된 노력 (0–100, Pennanen et al., 2026) |
| 가설 | **H1** B > A (PO). RQ2: IA와 PO의 관계 (조건 포함 회귀) |

### 조건별 조작

| | A · Single-Prompt | B · Iterative Prompting |
|---|---|---|
| 프롬프트 작성 | 1회 | 최초 1회 + 결과 확인 후 수정 |
| 생성 횟수 | 1회 (수정·재생성 불가) | 최대 3회 (추가 2회) |
| 최종 이미지 | 생성된 1장 | 마지막으로 생성된 이미지 (선택 불가) |
| 제한 시간 | 6분 | 6분 (동일) |

### 두 조건 간 동일하게 통제되는 것
- 같은 세계관 텍스트(「등불의 군도」), 같은 과제 지시문
- 같은 생성 모델, 같은 숨은 스타일 접미사(`STYLE_SUFFIX`), 같은 출력 크기(768×1024, 3:4)
- AI 사용 **전에** 컨셉 시트 + 손 스케치 작성 (의도를 사전에 고정)
- 같은 사후 설문, 같은 순서

| 보고서 섹션 | 분석 | PDF 대응 |
|---|---|---|
| 1 | Cronbach's α (PO, IA, CC), AU 2문항 r / Spearman-Brown | "reliability re-checked on our data" |
| 2 | CC: Welch t (단측 B>A), Hedges' g + 95% CI, exact permutation, Mann-Whitney | Manipulation check |
| 3 | **PO: 동일 (H1)** | Main |
| 4a | AU: Welch t (양측) | Secondary |
| 4b | 저자 표기: Fisher exact (Myself vs. 그 외) + 전체 표 permutation χ² | Secondary |
| 5 | r(IA, PO) 전체/조건별, OLS `PO ~ IA + Cond`, 탐색적 `IA × Cond` | RQ2 |
| 6 | OLS `PO ~ Cond + Quality + Effort` | Covariates |
| 7–8 | 과정 로그 기술통계, 사전 특성 균형 점검 | Appendix A5 |

## 5. 설계상 주의할 점 (발표·보고서에 언급 권장)

1. **검정력**: 조건당 6명이면 80% 검정력(α=.05, 단측)에 **d ≈ 1.54**가 필요 (양측 ≈ 1.80). d = 0.8을 검출하려면 조건당 약 21명. → 제안서대로 효과크기와 CI 중심으로 보고하고, exact permutation test를 함께 제시 (12명이면 924개 배정 전부 열거 가능).
2. **B의 최종 이미지는 마지막 결과로 고정** (`B_FINAL_SELECTION: 'last'`): 여러 결과 중 '고르는' 관여가 섞이지 않도록 해서 "수정 가능 여부만 다르다"는 조작을 유지함. 단, B 참가자는 마지막 결과가 이전보다 나빠도 되돌릴 수 없음 → 안내 화면에 명시되어 있으며, 자유응답에서 이런 불만이 나오는지 확인.
3. **시간 차이**: A는 생성 단계가 짧게 끝남 → 노력(effort)이 B에서 높게 나올 가능성. 공변량 모델(섹션 6)과 `gen_seconds`로 해석.
4. **생성 지연/실패**: 실패한 생성은 횟수에 포함하지 않으며 로그에 남음. Pollinations 무료 티어는 B 참가자에게 대기를 강제하므로 본 실험에선 OpenAI(또는 유료 키) 사용 권장.
5. **번역 문항**: PO·CC·AU는 영어 원문을 번역/개작함 (앱에 영문 병기). 보고서에 번역 절차와 우리 데이터의 α를 기재.
